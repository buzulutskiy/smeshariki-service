# Смешарики — каталог серий по категориям

Интерактивный веб-сервис для просмотра всех 703 серий мультсериала «Смешарики» с разделением по 12 категориям: философия и взрослые смыслы, юмор, приключения, дружба, любовь, наука, спорт, творчество, мистика, праздники, обучающие и житейские истории.

## Возможности

- 📺 **703 серии** со всеми синопсисами (6 сериалов франшизы)
- 🏷️ **12 категорий** для интуитивной фильтрации
- 📅 **Три режима сортировки**: по дате выхода, номеру серии, алфавиту
- ✓ **Отметки «просмотрено»** с автосохранением
- 🔍 **Полнотекстовый поиск** по названию, синопсису, сериалам
- 💾 **Сохранение состояния**: активная категория, фильтры, поиск запоминаются
- 🌙 **Тёмная/светлая тема** (автоматическая по системе)

## Использование

### Локально

```bash
python3 смешарики-сервис/server.py 8742
# или
cd смешарики-сервис && python3 -m http.server 8742
```

Откройте `http://127.0.0.1:8742` в браузере.

### На сервере

Скопируйте папку `смешарики-сервис/` на сервер и запустите любой статический веб-сервер (nginx, Apache, Node.js express и т.д.).

## Структура

```
смешарики-сервис/
```

## Особенности

- Просмотренные серии становятся полупрозрачными и опускаются в конец списка
- Поиск индексирует названия, синопсисы, названия сериалов
- Состояние фильтров и активная категория сохраняются между сеансами
- Весь код находится в `index.html` + `data.js` (no build, no dependencies)
